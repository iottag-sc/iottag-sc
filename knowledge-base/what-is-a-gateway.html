What is a gateway?

A gateway relays real-time location information to the cloud server. This means that your information is accessible anywhere.

A gateway is a listening device typically used indoors, the gateway requires access to power and a network (ethernet/wifi/cellular) to function. The gateway receives 'bluetooth advertising' from tags, this allows the gateway to calculate the real-time location of each asset which has a tag attached.

Some of the features that you can get with a cloud solution are remote management and configuration of the system from anywhere. The gateway can even report battery levels of the tags. Firmware updates can be pushed over the air, for easy upgrades and security patches.
